# Sumo Manager 〜相撲部屋経営ゲーム〜

単一の HTML ファイルで動く、相撲部屋の経営ゲームです。ブラウザで `sumo_manager_vNN.html`(番号がいちばん大きいもの)を開けば遊べます。保存はブラウザの中(localStorage)に残ります。

## フォルダ
| 場所 | 中身 |
|---|---|
| `sumo_manager_vNN.html` | ゲーム本体(最新版) |
| `docs/` | 引き継ぎ資料(仕組み・データの出典・測定値・残りの作業) |
| `data/` | 実在のデータの元ファイル(年寄名跡・部屋・年寄・裏方・力士の初土俵・後援会費) |
| `patches/` | 前の版から次の版を作るパッチ(`python3 patches/patchNN.py 前の版.html 新しい版.html`) |
| `tests/` | 自動テスト(40 年の自動プレイ、画面、保存データの引き継ぎ) |

## 別のチャットで再開する
claude.ai のプロジェクト「sumo」の中で新しいチャットを開き、「続き」と送ります。Claude はプロジェクトの `claude/00_再開手順.md` と最新の引き継ぎ資料を読み、このリポジトリから最新版を取ってきて再開します。

## データについて
実名モードの力士・部屋・親方・裏方は 2026 年の実在のものです。能力は推定で、ゲーム内で起きる出来事はすべて架空です。本名は登録していません。出典は各版の引き継ぎ資料にあります。
